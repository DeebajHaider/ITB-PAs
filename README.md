# Programming Assignments - Introduction to Blockchain

This repository contains programming assignments for the **CSE-355: Introduction to Blockchain** course at **IBA Karachi**.

## Course Information

- **Course Code:** CSE-355
- **Course Title:** Introduction to Blockchain
- **Institution:** Institute of Business Administration (IBA), Karachi

## Repository Contents

This repository includes various programming assignments that cover fundamental concepts in blockchain technology, including:

- Block structure and validation
- Transaction handling
- Hashing and cryptographic functions
- Network communication
- Consensus mechanisms
- Mempool management
- Full node implementation

## Project Structure

Each assignment is organized in its own directory (e.g., `PA1/`, `PA2/`, etc.) containing:

- `Code/`: Source code files for the assignment
  - Main implementation files
  - Utility functions
  - Test cases

## Getting Started

### Prerequisites

- Python 3.x
- Basic understanding of blockchain concepts

### Running the Code

Navigate to the specific assignment directory and execute the main file:

```bash
cd PA1/Code/
python main.py
```

## Notes

- The project uses `.gitignore` to exclude unnecessary files (compiled Python files, environment files, automatic directories)
- Each assignment builds upon concepts from the Introduction to Blockchain course
